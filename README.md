## Project Description
This project is a browser-based Hangman game developed using HTML, CSS, JavaScript and JSON. The game selects a random word and hint, and the player tries to guess the word by selecting letters.
## Features
- Random word selection from a JSON file
- Hint provided for each word
- Interactive letter keyboard
- Correct guesses highlighted in green
- Incorrect guesses highlighted in red
- Hangman images update after incorrect guesses
- Win and loss messages
- Play Again button to restart the game
- Responsive design
- Fade-in animation
## Technologies Used
- HTML5
- JavaScript
- JSON
- SCSS
- CSS
## Project Structure
- `index.html` – Main webpage
- `images/` – Hangman images
- `json/` – Word list and hints
- `scripts/` – JavaScript game functionality
- `styles/` – SCSS and compiled CSS styles
## How to Play
1. Start the game.
2. Read the hint provided.
3. Select letters to guess the hidden word.
4. Avoid making six incorrect guesses.
5. Win by guessing the word correctly or restart using the Play Again button.
